Place the following files into this directory and then build the docker container:
* public_mm_data_lite_usabase_2022aa.zip  
* public_mm_data_lite_usabase_2022ab.zip
* public_mm_lite_3.6.2rc8_binaryonly.zip

These files are available from the Metamap Lite website at https://lhncbc.nlm.nih.gov/LHC-research/LHC-projects/NLP/MetaMapLite.html (UMLS license required).
